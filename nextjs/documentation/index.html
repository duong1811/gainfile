Welcome to Trackify Next.js

Thank you for downloading Trackify Next.js. This official document explains how to install, configure, map logic, and deeply customize your new premium Next.js dashboard template.

Trackify is built on highly optimized modern web technologies including Next.js 16 (App Router), React 19, Tailwind CSS, Framer Motion, and QuestLabs React SDK. It features a stunning "Aurora Glassmorphism" UI, built-in dynamic Dark/Light modes, RTL (Right-to-Left) direction layout support, and over 65+ fully coded application pages ranging from Kanban Taskboards and Sales CRMs to IT Asset Trackers and Financial Invoices. Version 1.1 introduces 6 additional specialized modules including AI-driven Predictive Insights and Wellness monitoring.

Installation & Setup

Follow these quick steps to get a local development server running seamlessly right on your machine.

Prerequisites

You must have Node.js (v18.0 or higher) installed on your system.

1. Unzip and Open

Extract the downloaded ThemeForest ZIP archive and open your terminal or command prompt. You must cd code to enter the subdirectory where package.json is located.

2. Install NPM Dependencies

Run the following command to download all necessary NPM library packages. This might take a few minutes: 

npm install

Alternatively, if you prefer Yarn:

yarn install

3. Run Local Development Server

Start the Next.js development engine. It automatically recompiles whenever you save a file (HMR):

npm run dev

Navigate to http://localhost:3000 in your web browser.

4. Build & Start for Production

To generate a highly optimized Next.js production build, run: 

npm run build

To start the production server locally, run:

npm run start

│   │   ├── lib/                # Utility libraries & helper functions (CVA, utilities)
│   │   └── views/              # Page view components

│   └── tailwind.config.js      # Tailwind configuration
└── documentation/              # Contains these docs (HTML, CSS)

Custom Theming & Brand Colors

Trackify does not rely heavily on massive Tailwind Config overwrites for color swaps. Instead, we rely purely on the speed of native CSS Variables mapped directly into Tailwind utility classes via src/index.css. This drastically reduces JavaScript overhead and allows instantaneous switching between themes natively through the browser renderer.

Editing Colors

Navigate to src/index.css. You will find the root CSS tokens:

:root {
  /* Default to dark theme values */
  --aurora-1: #4f46e5;
  --aurora-2: #7c3aed;
  --aurora-3: #2563eb;
  --aurora-4: #0891b2;
  --glass-bg: rgba(255, 255, 255, 0.03);
  --glass-border: rgba(255, 255, 255, 0.08);
  --text-primary: #ffffff;
  --text-secondary: rgba(255, 255, 255, 0.6);
  --bg-primary: #030712;
}

body.light-theme {
  /* Light Mode Override Values */
  --aurora-1: #6366f1;
  --aurora-2: #8b5cf6;
  --aurora-3: #3b82f6;
  --aurora-4: #06b6d4;
  --glass-bg: rgba(255, 255, 255, 0.6);
  --glass-border: rgba(0, 0, 0, 0.05);
  --text-primary: #1f2937;
  --text-secondary: #4b5563;
  --bg-primary: #f8fafc;
}

Simply change the HEX/RGBA codes in these tokens to brand the entire application globally. For instance, modifying --aurora-1 to a Hex color of your brand instantly updates thousands of components mapping to that variable.

Dark Mode & RTL Global Context API State

We handle complex layout states via src/context/ThemeContext.jsx. Inside any component, you can trigger UI shifts by accessing properties provided via the custom hook: const { isDarkMode, toggleTheme, isRTL, toggleDirection, isSidebarCollapsed, toggleSidebar } = useTheme();

Next.js App Router & Adding New Pages

Logical routing is handled via folder-based routing inside the Next.js src/app directory.

We use route groups and layouts to structure our application. For example, dashboard pages are placed inside the (dashboard) folder group, which applies the dashboard layout (Sidebar, Topbar, and aurora background animation) defined in src/app/(dashboard)/layout.jsx. Authentication pages (like /login or /register) bypass the dashboard layout since they are situated outside the (dashboard) folder structure.

How to add your own brand new page:

  1. Create a new directory inside the dashboard route group, e.g., src/app/(dashboard)/your-new-page.
  2. Create a page.jsx file inside that directory: 
    "use client";
import React from 'react';
// Import your custom view or write JSX directly
export default function Page() {
  return <div>Your Page Content</div>;
}
  3. The page will be automatically mapped to the URL route: /your-new-page.
  4. Open src/components/Sidebar.jsx and append a subItem/Item inside the menuItems array to make it accessible in the sidebar navigation interface.

Standardized UI Component Library (CVA)

Trackify features a high-fidelity, modular UI library built using Class Variance Authority (CVA). This allows for a declarative, variant-aware component system that ensures strict design consistency while providing maximum flexibility for developers.

Variant-Aware Components

Core components like Buttons, Badges, Cards, and Inputs now support standardized variants (primary, glass, aurora, danger) through a clean, prop-driven API.

Advanced Interactive Modules

Highly optimized Dropdowns, Modals, and Tooltips with managed stacking contexts (z-index) and overflow-aware rendering for seamless UX.

Framer Motion Integration

Every component is wrapped with physics-based micro-animations, providing a tactile and premium feel to all user interactions.

Glassmorphic Design Tokens

Direct mapping to CSS variables ensures that all components respect the global "Aurora" design language across both Dark and Light modes.
